# CS Retro

<div class="hero" markdown>

**The Counter-Strike feel you remember. Room for new ideas.**

Familiar maps, tactical teamplay and an unmistakable retro character —
with an evolving interface and selected ideas from modern games.

</div>

CS Retro is an independent community project built on Xash3D-FWGS.
We are not trying to adopt every modern mechanic or simply freeze the classic game in time:
a change should fit the Counter-Strike feel and make the experience better.

[Get started](getting-started.md){ .md-button .md-button--primary }
[Get involved](contributing.md){ .md-button }

!!! warning "Work in progress"
    This is not a finished game package. Features, visuals and balancing are evolving.
    Original game data is not included; additional experimental assets are not yet generally
    available. Read the [project status](status.md) before building.

automatically mean it will be implemented.
