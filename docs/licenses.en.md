# Licenses and game content

CS Retro contains sources from multiple projects. There is **no blanket license clearance for
the entire repository or a complete game package**.
Each component's existing license text, copyright notices and exceptions remain authoritative.

| Component | Documented licensing |
| --- | --- |
| Xash3D-FWGS | GPL-3.0-or-later; license text in the engine tree |
| Client body from cs16-client | GPL-2.0-or-later with Valve HL1 SDK exception; `client/body/LICENSE` |
| ReGameDLL_CS | MIT, plus Valve SDK notices in source files; `server/game/LICENSE` |
| NextClient and NitroApi portions | No root LICENSE in the imported snapshot; use/redistribution rights unresolved |
| NextClientServerApi | MIT; retain the corresponding notices |
| Valve SDK | Separate SDK terms; do not equate them generally with GPL/MIT |
| Noto Sans / Noto Sans Mono | SIL OFL 1.1; included at `data/ui-overrides/platform/resource/csretro_fonts/OFL.txt` |
| Xonotic announcer WAVs | GPL (xonotic-data); notice at `data/ui-overrides/cstrike/sound/announcer/NOTICE.txt` |
| Other libraries | Their own notices in their respective source directories |

## Open review

Public repository visibility does not replace a license.
NextClient/NitroApi portions and additional imported grenade assets in particular require further
clarification. This page is a technical provenance overview, not legal advice or an assurance
of redistribution rights.

## Game data and images

Original maps, models, sounds and other CS 1.6/Half-Life data are not supplied as a game package.
Local import requires your own installation.
Documentation screenshots depict the game with these contents; they do not transfer rights
to the assets shown.

Authors and redistribution terms for additional model/effect packs must be documented before
an asset release. A filename or archive alone is not enough.
We do not credit unidentified third-party authors' work to CS Retro.

## Contributions

Retain notices and identify the source, author, license and scope of third-party material.
Do not contribute material without a documented basis for using it.
Report missing or incorrect attribution through a documentation issue.
