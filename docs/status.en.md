# Project status

**Overview dated 11 September 2026.** CS Retro is in active development.
A screenshot or successful compile does not establish that the whole game works correctly.

| Area | Status |
| --- | --- |
| Linux x86_64 | Local builds and playtests available; no general support guarantee |
| Windows / macOS | 64-bit targets; complete build/runtime matrix still pending |
| Team and class menus | Playable; live team preview most recently received positive in-game feedback |
| Buy menu | Available; presentation and interaction are still being refined |
| Molotov / Incendiary | Native implementation exists; input, effects and animations still have reported problems |
| Bots | ZBot code in the GameDLL; full competence with new grenades not certified by testing |
| Distribution | No current complete game package; asset acquisition and license review remain open |
| Website | Player and developer documentation in German and English |

## Known limitations

- The first M1 press does not take effect in some grenade sequences.
- Incendiary flames have been reported invisible while damage still occurs.
- Viewmodels, hold/throw animations and movement feel need further checking.
- Buy-menu spacing, readability and item presentation are not final.
- Console and HUD presentation/interaction problems have been reported.
- A complete new build requires additional assets that are not generally provided yet.

This is a list of known problem areas, not necessarily every current bug.
[Issues](https://github.com/benjarogit/csretro/issues) are the public home for reproductions and discussion.
A successful compilation alone is not sufficient to close a gameplay bug.

## Direction

Preserve the classic feel, improve usability and selectively integrate suitable modern ideas.
Useful proposals describe the problem, the desired player experience and possible trade-offs.
No delivery dates are promised here.
