# Security / Sicherheit

Bitte veröffentliche keine Zugangsdaten, Exploits mit privaten Daten oder persönliche Logs in Issues.
Melde Sicherheitslücken über
[GitHubs private Sicherheitsmeldung](https://github.com/benjarogit/csretro/security/advisories/new).

Please do not post credentials, exploits containing private data or personal logs in public issues.
Use [GitHub private vulnerability reporting](https://github.com/benjarogit/csretro/security/advisories/new).

Include the affected commit, platform, impact and a minimal reproduction without third-party data.
Development snapshots do not have a guaranteed security-support period or response SLA.
