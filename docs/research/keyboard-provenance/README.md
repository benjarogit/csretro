# Keyboard catalog provenance

`client/assets/cstrike/gfx/shell/kb_act.lst` / `kb_def.lst` were removed from the product tree (2026-09-02).

They were full copies of classic CS lists (with drift, e.g. `lookat`) and must **not** be treated as CS-Retro overlay or runtime source.

Runtime: Steam-bootstrapped `gamedata/cstrike/gfx/shell/kb_*.lst`.
Overlays: `data/ui-overrides/cstrike/gfx/shell/kb_*_overlay.lst` — own additions only.
