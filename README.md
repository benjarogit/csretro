## Deutsch

CS Retro verbindet den Charakter des klassischen Counter-Strike mit ausgewählten Ideen moderner Spiele:
vertraute Atmosphäre, taktisches Teamspiel und eine weiterentwickelte Bedienung.
Eine eigenständige 64-Bit-Desktop-Spielerfahrung auf Basis von Xash3D-FWGS — kein offizielles Valve-Projekt.

Wir entwickeln öffentlich. Spielerfeedback, Wünsche, Fehlerberichte, Übersetzungen und Codebeiträge
sind willkommen. Du musst kein Entwickler sein, um mitzumachen.

**Entwicklungsstand, kein fertiges Spielepaket.** Originale CS-1.6-Spieldaten werden nicht mitgeliefert.
Eine eigene lokale Steam-Installation ist für den Datenimport erforderlich; zusätzliche experimentelle
Granaten-Assets sind noch nicht allgemein bereitgestellt. Plattformstatus, Build-Anleitung und offene
Einschränkungen stehen in der [Dokumentation](https://benjarogit.github.io/csretro/).
Die Rechte gelten komponentenweise; siehe [Lizenzhinweise](https://benjarogit.github.io/csretro/licenses/).

## English

CS Retro combines classic Counter-Strike's identity with selected ideas from modern games:
a familiar atmosphere, tactical teamplay and an evolving interface.
An independent 64-bit desktop experience built on Xash3D-FWGS — not an official Valve project.

Development happens in the open. Player feedback, feature requests, bug reports, translations
and code contributions are welcome. You do not need to be a developer to take part.

**Work in progress, not a finished game package.** Original CS 1.6 game data is not included.
Import requires your own local Steam installation; additional experimental grenade assets are not yet
generally available. See the [documentation](https://benjarogit.github.io/csretro/en/) for platform status,
build instructions and limitations. Licensing is component-specific:
[license notes](https://benjarogit.github.io/csretro/en/licenses/).
