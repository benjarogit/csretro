# Lizenzen und Spielinhalte

CS Retro enthält Quellen verschiedener Projekte. Es gibt **keine pauschale Lizenzfreigabe
für das gesamte Repository oder ein komplettes Spielepaket**.
Die vorhandenen Lizenztexte, Copyright-Hinweise und Ausnahmen der jeweiligen Komponenten bleiben maßgeblich.

| Komponente | Dokumentierter Lizenzstand |
| --- | --- |
| Xash3D-FWGS | GPL-3.0-or-later; Lizenztext im Engine-Baum |
| Client-Body aus cs16-client | GPL-2.0-or-later mit Valve-HL1-SDK-Ausnahme; `client/body/LICENSE` |
| ReGameDLL_CS | MIT, außerdem Valve-SDK-Hinweise in den Quellen; `server/game/LICENSE` |

| Weitere Bibliotheken | Eigene Notices in den jeweiligen Quellverzeichnissen |

## Offene Prüfung

Die öffentliche Sichtbarkeit eines Repositories ist kein Ersatz für eine Lizenz.
Insbesondere die NextClient-/NitroApi-Anteile und zusätzlich importierte Granaten-Assets
benötigen weitere Klärung. Diese Seite ist ein technischer Herkunftsüberblick,
keine Rechtsberatung oder Zusicherung der Weiterverteilbarkeit.

## Spieldaten und Bilder

Originale Maps, Modelle, Sounds und sonstige CS-1.6-/Half-Life-Daten werden nicht als Spielepaket
bereitgestellt. Der lokale Import setzt eine eigene Installation voraus.
Die Dokumentations-Screenshots zeigen das Spiel mit diesen Inhalten; sie übertragen
keine Rechte an den dargestellten Assets.

Die Urheber und Weitergabebedingungen zusätzlich verwendeter Modell-/Effektpakete müssen vor
einem Asset-Release dokumentiert werden. Ein Dateiname oder Archiv allein reicht dafür nicht aus.
Wir schreiben unbekannte Autoren nicht dem CS-Retro-Projekt zu.
